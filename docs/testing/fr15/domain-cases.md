# FR-15 — Test case nguồn của Domain Testing và Supplementary

## Cách đọc bảng

Bảng gồm 143 ca nguồn Domain Testing và 11 ca Supplementary. Mỗi dòng giữ source ID, rule, obligation, input chính, expected result và trạng thái thiết kế. Các ca Supplementary không được cộng vào mẫu số Domain Testing hoặc BVA.

Preconditions chung: reset fixture trước case; dùng đúng partition token; ID được chọn phải tồn tại khi Update/Delete hoặc Read detail, trừ probe ID vắng. Các bước chung là reset → snapshot → thao tác ở đúng tầng API/WEB → ghi request/response hoặc UI → đối chiếu dữ liệu trước/sau; với WEB còn đối chiếu trước và sau reload.

Payload đầy đủ, preconditions và steps của từng ID nằm trong [source-cases.json](../../../tests/fr15/source-cases.json); dữ liệu fixture nằm trong [fixtures.json](../../../tests/fr15/fixtures.json). Bảng chỉ rút gọn input để dễ đọc, không thay thế payload. `L` là số ký tự ASCII; ca Unicode ghi rõ khi chưa biết đơn vị đếm.

`Not Run`, `actual=null` và `evidence=[]` là trạng thái baseline đã freeze. Actual result sau execution được ghi riêng trong [test-results.md](test-results.md). Dùng [suite-review.md](suite-review.md) để tìm canonical ID tương ứng.
