# Ảnh bằng chứng cross-platform

Ảnh được lấy từ cửa sổ trình duyệt thật trong video BrowserStack hoặc chụp trực tiếp màn hình thiết bị Android thật. Email sinh viên được hiển thị trên trang lúc chụp; không ghép thanh trình duyệt hoặc thêm watermark sau khi chụp.

Mỗi ảnh đã được rà trực tiếp: thanh trình duyệt + địa chỉ URL + màn hình web tương ứng + email `23120367@student.hcmus.edu.vn`. Trên Android, Chrome có thể rút gọn địa chỉ trong thanh native; watermark ghi URL đầy đủ.

## Độ phủ hiện tại

**208 ảnh đã duyệt / 208 ô có kết quả cần ảnh; còn 0 ô thiếu ảnh.**

- Chrome / Windows 11: 70 ảnh
- Firefox / Windows 11: 69 ảnh
- Chrome / Android / Galaxy S23 thật: 69 ảnh

Các ô Not Run chờ IME/screen-reader không được đổi thành Passed/Failed bằng việc chụp ảnh. Kết quả cũ trong báo cáo lịch sử được giữ nguyên; ảnh bổ sung có ngày, phiên và môi trường riêng trong manifest. Ảnh Windows/Android không được coi là ảnh macOS gốc của báo cáo cũ.
