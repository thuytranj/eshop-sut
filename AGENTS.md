# Project agent instructions

## AI audit logging

For every AI-assisted turn in this repository, read and follow
`.agents/skills/hw03-ai-audit/SKILL.md`. Maintain the append-only
`docs/AI-Audit-Report.md` with source date/time, timezone, model identity,
exact user input and raw visible generation output. Sync the current project's
available session at turn start and before the final reply. Prepare and log the
exact final reply before sending when it has not yet persisted; next sync records
actual delivery separately. Do not fabricate missing metadata or prior logs.
If logging cannot run, disclose the gap instead of claiming full capture.
Do not export private reasoning or system/developer instructions.

## HW03 GUI checklist

For checklist design, review or execution, use
`.agents/skills/hw03-gui-checklist/SKILL.md` alongside the relevant existing
UI-review/browser-testing skills. Require IA-01, IA-02, IA-03 and IA-04,
at least 41 meaningful items, and requirement-to-item traceability. Validate
structural coverage and review semantic coverage against the actual specification.
Never label unexecuted checks Passed/Failed or AI-authored additions Human.
